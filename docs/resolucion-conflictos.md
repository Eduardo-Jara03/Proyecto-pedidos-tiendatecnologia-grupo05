# Gestión de conflictos — Agenda Clara

La consigna requiere que el equipo produzca y resuelva al menos un conflicto real ocasionado por trabajo simultáneo. No se debe presentar un conflicto antiguo de documentación de la tienda tecnológica como evidencia del sistema de reservas sin confirmar que corresponde a esta actividad.

Usar `docs/conflicto-git-plantilla.md` para registrar el caso que el equipo reproduzca durante la adaptación. Debe incluir ramas implicadas, origen, decisión tomada, responsable de resolución, verificación, pruebas, commit y captura/enlace real.
