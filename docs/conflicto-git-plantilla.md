## Ejercicio reproducible sugerido

Coordinen dos ramas temporales a partir de la misma base y editen deliberadamente la misma línea de un archivo de documentación. Integren primero una rama y después intenten integrar la otra. Resuelvan el conflicto en colaboración, ejecuten las verificaciones pertinentes y documenten el caso real. No fabriquen capturas ni indiquen que se produjo si no se hizo.
