# Lista de evidencias para la entrega

Completar con enlaces y capturas reales; no usar esta lista como sustituto de la evidencia.

- [ ] URL del repositorio accesible.
- [ ] Tablero GitHub Projects con estados Pendiente, Seleccionado, En progreso, En revisión y Hecho.
- [ ] Actividades asignadas a los integrantes y contribuciones verificables.
- [ ] Ramas de funcionalidad publicadas.
- [ ] Pull Request con revisión real de una persona distinta al autor.
- [ ] Conflicto real reproducido y resuelto, con captura/commit.
- [ ] Pruebas automatizadas ejecutadas en el equipo.
- [ ] Prueba manual de clientes, servicios y reservas.
- [ ] Tag/commit de versión estable.
- [ ] Evidencia de sustentación/asistencia, según lo indicado por el docente.
